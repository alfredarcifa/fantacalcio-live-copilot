# Fantacalcio Live Copilot v2.5

Dashboard React + Vite + Tailwind CSS v4 per asta Classic a 8 squadre, budget 1000, modificatore difesa e capitano.

## Funzioni

- dashboard sintetica;
- listone completo e lista strategica 25;
- asta live con budget, slot e massimo rilancio;
- otto fantallenatori e rose persistite in localStorage;
- classifiche su quotazioni e FVM realmente disponibili;
- immagini giocatore;
- versione build visibile.

## UI

Tailwind CSS v4 viene integrato tramite `@tailwindcss/vite`. Non viene usato SCSS perché Tailwind v4 svolge il ruolo di preprocessore e usa design token CSS-first tramite `@theme`.
